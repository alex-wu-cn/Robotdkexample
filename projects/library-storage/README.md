# 图书馆收纳项目

用 RoboDK 交互式搭建的完整工作站。

## 打开方式

1. 启动 RoboDK（5.6.5）
2. `File` → `Open` → 选择 `library-storage-project.rdk`

| 项目 | 值 |
| --- | --- |
| 文件 | `library-storage-project.rdk` |
| 大小 | 35.85 MB |
| 格式 | RoboDK 工作站（二进制打包） |
| 版本 | RoboDK 5.6.5 |
